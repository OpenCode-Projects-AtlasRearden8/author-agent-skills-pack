# Workflow Notes for the Research Summarizer

Per summary batch:

1. List the folder contents; confirm all files are author-supplied (no fetching).
2. For each file: extract text, write the ledger entry (TL;DR, key numbers with page/section, usable-for, cautions), append to `research/ledger.md` under the right topic heading.
3. Anything uncertain → `[verify]`, never a guess.
4. On request with ≥ 5 entries in a topic: write the `## Digest — <topic>` subsection citing entry titles; state disagreements plainly.
5. Model-assisted glosses (optional, only if the author asked): label them `model-assisted` and keep them inside `[begin draft]/[end draft]` markers for review.

Rules: no web fetching, no invented citations, no silent merges of conflicting claims, no emotional words added to a source's meaning ("shocking" is the author's call). Names of real people from sources are summarized only in the context the source itself provides.
